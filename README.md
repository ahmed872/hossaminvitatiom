# 💌 Hossam & Nada — Digital Wedding Invitation

دعوة زفاف رقمية تفاعلية — جواب ملكي مختوم بشمع بيتفتح ويكشف الدعوة.

**الفرح:** الأربعاء 29 يوليو 2026 — الساعة 8 مساءً — قاعة وادي العمر، صفط تراب، المحلة الكبرى

## ✨ المميزات
- جواب (Envelope) ثلاثي الأبعاد بختم شمع ذهبي — اضغط عليه يفتح ويطلع الدعوة
- كاونت داون حي لحد لحظة الفرح
- قسم صور الطفولة (بولارويد) للعريس والعروسة
- زرار لوكيشن القاعة على Google Maps + زرار "ضيف على الكالندر"
- تخصيص اسم الضيف من اللينك: `?to=اسم_الضيف`
  - مثال: `index.html?to=أحمد` → "دعوة خاصة لـ أحمد"
- جزيئات ذهبية + كونفيتي عند فتح الجواب + ورد متساقط

## 🖼️ إضافة صور الطفولة
حط الصورتين دول في فولدر `images/`:
- `images/hossam-child.jpg` — صورة حسام وهو صغير
- `images/nada-child.jpg` — صورة ندى وهي صغيرة

لو الصور مش موجودة، بيظهر بلاي هولدر تلقائيًا.

## 🚀 النشر
ملف واحد `index.html` — ينفع مباشرة على Vercel أو GitHub Pages أو Netlify.
